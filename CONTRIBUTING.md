# Contributing to ChatPDF

Thanks for your interest! This is a personal portfolio project, but contributions are welcome.

## How to contribute

1. Fork the repo and create a feature branch from `main`.
2. Follow the local setup instructions in the [README](./README.md).
3. Make your changes; keep them focused and well-tested.
4. Run the test suite before opening a PR: `cd backend && python -m pytest tests/ -v`
5. Open a pull request with a clear description of what you changed and why.

## Reporting bugs

Open a GitHub issue describing the problem, the steps to reproduce it, and what you expected to happen.

## Code style

- **Python**: follow PEP 8. Use type hints where practical.
- **JavaScript**: follow the existing ESLint config (`eslint-config-next`).
- Keep commits atomic and write meaningful commit messages.
